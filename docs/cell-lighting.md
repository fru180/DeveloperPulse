# セルの光り方

DeveloperPulseは、取得した音声を周波数ごとの音量に分解し、その値をセルの明るさへ変換します。画面には **Live Cells** と **Timeline** の2つの表示モードがあり、セルの並びと発光の仕組みが異なります。

## 音声解析の流れ

1. 音声を40Hz〜16kHzの64帯域に分けます。
2. 各帯域の音量をデシベル（dB）で求めます。
3. 選択中のモードに合わせて帯域をまとめ直します。
4. **Sensitivity**の値を加え、セルの明るさへ変換します。

`Sensitivity`をプラスにすると小さな音にも反応しやすくなり、マイナスにすると強い音だけに反応します。調整範囲は-18dB〜+18dBです。

ブラウザ版とデスクトップ版は、解析結果を25msを基準に更新し、2種類の解析窓を併用します。4,096サンプル（48kHzで約85ms）の解析結果を通常の色とTimelineに使い、2,048サンプル（約43ms）の解析結果は明確な音の立ち上がりを早く反映するためだけに使います。短い解析結果は持続音の色を置き換えたり、通常の色を暗くしたりしません。どちらもWeb Audio仕様と同じBlackman窓とFFT正規化を使用し、解析開始直後に不足する過去のサンプルは無音として扱います。

## Live Cells

Live Cellsは、横方向に**周波数**、縦方向に**音の立ち上がり（アタック）の強さ**を割り当てた53列×7行、合計371個のセルで現在の音を表示します。

```text
              低い周波数  ───────────────→  高い周波数
Strong        □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
Medium        □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
Soft          □ □ □ □ □ □ □ □ □ □ □ □ □
```

### 横方向：周波数

64帯域の解析結果を、低音から高音の順序を保ったまま53列へまとめます。各列の色は、その周波数に含まれる音の強さを表します。

### 縦方向：アタックの強さ

音が聞こえる強さに達すると、各周波数列の一番下のセルが点灯します。直前の解析結果から音量が急に上がるほど、点灯するセル数が上へ伸びます。変化量は50msあたりのdB差へ換算するため、解析の取得間隔が変わっても同じ立ち上がりは同じ高さになります。

- 変化が小さい、または持続音だけの場合は1セル
- 変化が大きいほど2〜6セル
- 最も強い立ち上がりでは7セル

検出したアタックの高さは80ms保持し、その後280msを基準に1セルまで下がります。音量そのものは上昇時に15ms、下降時に180msを基準として目標値へ近づくため、点灯は素早く、消灯は少し滑らかに見えます。

### 明るさ

感度調整後の音量を-72dB〜-30dBの範囲で0〜1へ正規化し、点灯中のセルを次の5段階で描画します。

|     正規化した強さ | 表示   |
| -----------------: | ------ |
|           0.10未満 | 消灯色 |
| 0.10以上、0.38未満 | 弱     |
| 0.38以上、0.68未満 | 中     |
| 0.68以上、0.90未満 | 強     |
|           0.90以上 | 最大   |

## Timeline

Timelineは、横方向に**時間**、縦方向に**周波数帯**を割り当てます。

```text
高音  6k–16kHz    □ □ □ □ □ □ □ □ □ □ □
      2.5k–6kHz   □ □ □ □ □ □ □ □ □ □ □
      1k–2.5kHz   □ □ □ □ □ □ □ □ □ □ □
      400Hz–1kHz  □ □ □ □ □ □ □ □ □ □ □
      150–400Hz   □ □ □ □ □ □ □ □ □ □ □
      60–150Hz    □ □ □ □ □ □ □ □ □ □ □
低音  40–60Hz     □ □ □ □ □ □ □ □ □ □ □
                  過去  ───────────────→  現在
```

解析結果を7つの周波数帯にまとめ、直前の値を使って急激な明るさの変化を滑らかにします。500msごとに新しい列を右端へ追加し、古い列を左へ送ります。53列で約26.5秒分の変化を確認できます。

最下段は、解析対象の下限と同じ40〜60Hz帯です。

### 明るさの判定

Timelineは、感度調整後の音量を5段階へ変換します。

|                 音量 |          明るさ |
| -------------------: | --------------: |
|            -72dB未満 |     0（消灯色） |
| -72dB以上、-60dB未満 |               1 |
| -60dB以上、-48dB未満 |               2 |
| -48dB以上、-36dB未満 |               3 |
|            -36dB以上 | 4（最も明るい） |
