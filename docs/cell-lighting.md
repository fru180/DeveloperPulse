# セルの光り方

DeveloperPulseは、取得した音声を周波数ごとの音量に分解し、その値をセルの明るさへ変換します。画面には **Live Cells** と **Timeline** の2つの表示モードがあり、セルの並びと発光の仕組みが異なります。

## 音声解析の流れ

1. 音声を40Hz〜16kHzの64帯域に分けます。
2. 各帯域の音量をデシベル（dB）で求めます。
3. 選択中のモードに合わせて帯域をまとめ直します。
4. **Sensitivity**の値を加え、セルの明るさへ変換します。

`Sensitivity`をプラスにすると小さな音にも反応しやすくなり、マイナスにすると強い音だけに反応します。調整範囲は-18dB〜+18dBです。

## Live Cells

Live Cellsは、横方向に**周波数**、縦方向に**反応速度**を割り当てた53列×7行、合計371個のセルで現在の音を表示します。

```text
              低い周波数  ───────────────→  高い周波数
Fast          □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
Medium        □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
              □ □ □ □ □ □ □ □ □ □ □ □ □
Slow          □ □ □ □ □ □ □ □ □ □ □ □ □
```

### 横方向：周波数

64帯域の解析結果を、低音から高音の順序を保ったまま53列へまとめます。同じ列にある7個のセルは同じ周波数の音量を参照し、同じ明るさを目標にします。

### 縦方向：反応速度

すべての行は35msを基準に素早く点灯します。音が弱くなった後の消え方だけが行ごとに異なります。

|  行 | 表示上の位置 | 減衰の基準時間 |
| --: | ------------ | -------------: |
|   1 | Fast         |           80ms |
|   2 |              |          140ms |
|   3 |              |          240ms |
|   4 | Medium       |          400ms |
|   5 |              |          650ms |
|   6 |              |        1,000ms |
|   7 | Slow         |        1,600ms |

上の行ほど音の変化を細かく追い、下の行ほど長い残光を残します。表の時間は完全に消えるまでの固定時間ではなく、目標の明るさへ近づく速さを決める値です。

### 通常の明るさ

感度調整後の音量を-72dB〜-30dBの範囲で0〜1へ正規化し、次の4段階で描画します。

|     正規化した強さ | 表示   |
| -----------------: | ------ |
|           0.10未満 | 消灯色 |
| 0.10以上、0.38未満 | 弱     |
| 0.38以上、0.68未満 | 中     |
|           0.68以上 | 強     |

通常の発光では最も明るい色を使わず、ピーク発光のために残しています。

### ピーク発光

次のどちらかを検出すると、該当する周波数列へ最も明るい色を重ねます。

- 瞬間的に音量が大きく上昇したとき
- 非常に大きな音が持続したとき

ピークの明るさは約180msで消えます。同じ大きな音が続いている間は繰り返し点滅せず、いったん音が弱くなってから次のピークを受け付けます。

## Timeline

Timelineは、横方向に**時間**、縦方向に**周波数帯**を割り当てます。

```text
高音  6k–16kHz    □ □ □ □ □ □ □ □ □ □ □
      2.5k–6kHz   □ □ □ □ □ □ □ □ □ □ □
      1k–2.5kHz   □ □ □ □ □ □ □ □ □ □ □
      400Hz–1kHz  □ □ □ □ □ □ □ □ □ □ □
      150–400Hz   □ □ □ □ □ □ □ □ □ □ □
      60–150Hz    □ □ □ □ □ □ □ □ □ □ □
低音  20–60Hz     □ □ □ □ □ □ □ □ □ □ □
                  過去  ───────────────→  現在
```

解析結果を7つの周波数帯にまとめ、直前の値を使って急激な明るさの変化を滑らかにします。500msごとに新しい列を右端へ追加し、古い列を左へ送ります。53列で約26.5秒分の変化を確認できます。

解析対象は40Hzから始まるため、最下段の20〜60Hz帯で実際に取得する範囲は40〜60Hzです。

### 明るさの判定

Timelineは、感度調整後の音量を5段階へ変換します。

|                 音量 |          明るさ |
| -------------------: | --------------: |
|            -72dB未満 |     0（消灯色） |
| -72dB以上、-60dB未満 |               1 |
| -60dB以上、-48dB未満 |               2 |
| -48dB以上、-36dB未満 |               3 |
|            -36dB以上 | 4（最も明るい） |

## カラーテーマ

ライト表示とダーク表示では異なる配色を使いますが、どちらも5段階の対応関係は同じです。画面下部の凡例では、**Less**から**More**へ進むほど音が強いことを示します。
